# CLAUDE.md — omniskill

OmniSkill is unified skill infrastructure for AI agents in Go: Skill/Tool/Role abstractions, MCP server and client bridging, and pack-based skill distribution (registry, loader, installer, ClawHub). Specs live in `docs/specs/` (PRD, TRD, PLAN, ROADMAP); read them before implementing.

## VisionStudio
